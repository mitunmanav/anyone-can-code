# Privacy Policy — Anyone Can Code

_Last updated: 2026-07-06_

## Short version

Anyone Can Code runs entirely on your machine. It does not collect, transmit, or sell any data.

## What the plugin stores

All plugin data lives inside your own project folder, under `.codex/anyone-can-code/`:

- Workflow state (what you are building, what is next)
- Portable Markdown memory notes (lessons and decisions you chose to save)
- Local logs used for verification and debugging

Nothing leaves your computer. There is no telemetry, no analytics, no remote server operated by this project.

## What the plugin does NOT do

- No account, no sign-up, no tracking
- No network calls of its own — any network activity happens through Codex itself under your control
- No reading of files outside the project you opened

## Your data, your control

Delete `.codex/anyone-can-code/` in a project and every trace of the plugin's state for that project is gone.
