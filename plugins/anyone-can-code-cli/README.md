# Anyone Can Code CLI — same plugin

**One plugin** for Desktop and CLI: install **Anyone Can Code** (`plugins/anyone-can-code`).

| Host | Install name | Auto memory |
|------|----------------|-------------|
| Codex Desktop | Anyone Can Code | **Yes** — trust hooks |
| Codex CLI | Anyone Can Code (same) | **Yes** — trust hooks (`/hooks`) |

Version: see main plugin **v2.0.0-beta.5**.

Do **not** install a separate CLI-only package.

Host-only (Desktop/web): Scheduled tasks UI, Sites, some app chrome — not a second ACC product.
