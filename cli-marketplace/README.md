# Anyone Can Code — CLI marketplace

Thin Codex marketplace catalog for **CLI only**.

Desktop users should paste the repo URL instead (main marketplace lists Desktop only).

## Add this marketplace

```bash
codex plugin marketplace add mitunmanav/anyone-can-code --ref main --sparse cli-marketplace
```

Or after clone:

```bash
codex plugin marketplace add ./cli-marketplace
```

Then install **Anyone Can Code CLI** from `/plugins`, trust hooks with `/hooks`, run `$setup`.
